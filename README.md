
# 🏰 Tower Defense - Консольная стратегия

Консольная Tower Defense на чистом JavaScript. Защити базу от врагов, строй башни и выживай как можно дольше!

## 🚀 Быстрый старт

```bash
# Запуск игры
node towerss.js
```
## Как играть
```
build <X> <Y> <basic|sniper|rapid>   # Построить башню
start wave                            # Начать волну
update                                # Сделать шаг
auto                                  # Авто-режим (шаг/сек)
stop                                  # Остановить авто-режим
towers                                # Список башен
status                                # Статус игры
help                                  # Помощь
exit                                  # Выход
```
 ## Тип	Цена	Урон	Радиус	Скорость
basic 🏰	100💰	20	3	Средняя

sniper 🗼	200💰	50	5	Медленная

rapid 🗻	150💰	10	2.5	Быстрая


## Стартовые условия
Жизни: 20 ❤️

Деньги: 300 💰

Карта: 15x15

Волны: от 5 до 15 врагов (усложняются)
